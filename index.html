Run the interactive tools locally

These apps expect your dataset paths via environment variables.

  1. Set DATASET_ROOT (or DATASET_IMAGES_DIR / DATASET_LABELS_DIR).
  2. Install dependencies (Streamlit/SAHI/Flask as needed).
  3. Run one of the entrypoints below.
# Streamlit dataset viewer
export DATASET_ROOT="/path/to/DATASETv3"
python -m streamlit run view_all.py

# Streamlit SAHI evaluator
export DATASET_ROOT="/path/to/DATASETv3"
export MODEL_PATH="/path/to/best.pt"
export SAHI_DEVICE="cpu"   # or "mps"/"cuda"
python -m streamlit run live/picture-inf-web-sahi.py

# Flask reviewer (bit flipper)
export DATASET_ROOT="/path/to/DATASETv3"
python bit-flipper/bit-flipper.py
Note: Vercel won’t host these ML-heavy Python UIs as-is (they need local files + long-running processes). Vercel is used here for the always-on project page + PR previews.
